# Personal Benchmark

A local-first VS Code extension that recommends a model and harness before a prompt is sent, and curates opted-in AI coding work into a private LLM benchmark. See [README.md](README.md) for the product description and [docs/model-recommendation.md](docs/model-recommendation.md) for the model policy.

## Commands

```bash
npm run compile     # generate icons, type-check, lint, bundle
npm run check-types # tsc --noEmit
npm run lint        # eslint src
npm test            # full extension test suite
npm run package     # production bundle
```

`npm test` runs `pretest`, which compiles and lints first. Run it before declaring work done.

## Architecture

Two bundles come out of [esbuild.js](esbuild.js):

- `dist/extension.js` from [src/extension.ts](src/extension.ts) — the extension host, with `vscode` external.
- `dist/prompt-hook.cjs` from [src/hookBridge.ts](src/hookBridge.ts) — a standalone Node script invoked as a `UserPromptSubmit` hook by Copilot, Claude Code, and Codex. It runs outside the extension host and must not import `vscode`.

[src/generated/providerIcons.ts](src/generated/providerIcons.ts) is generated by [generate-provider-icons.mjs](generate-provider-icons.mjs). Do not edit it by hand.

## Invariants

These are load-bearing. Tests cover each one; do not weaken them.

- **Capture is opt-in per folder.** Off is the default. The hook bridge rejects any prompt whose repository is outside the canonical allowlist, before writing any bytes.
- **Redaction happens before persistence.** [src/redaction.ts](src/redaction.ts) runs on every path that writes. Full prompt text is never persisted — only a redacted preview of at most 180 characters, a SHA-256 hash, and derived routing fields.
- **Nothing is uploaded.** There is no network path in this extension. Keep it that way.
- **Nothing is auto-submitted.** The handoff copies the draft and opens the harness. Copilot gets an unsent prefill via VS Code's partial-query command; Claude Code and Codex expose no supported prefill API, so the draft goes to the clipboard.
- **Hook edits are transactional.** [src/promptHookFiles.ts](src/promptHookFiles.ts) validates every target file before changing any of them, preserves unrelated settings and hooks, and removes only handlers it marked as its own.
- **The dashboard fits a narrow sidebar.** Layout is validated at 220×610 and 300×610.

## Conventions

- Tabs, single quotes, semicolons. Match the surrounding file.
- Tests use Mocha TDD style (`suite` / `test`), not BDD.
- Dashboard theme tokens are semantic (`--brand`, `--accent`, `--surface`) and defined once in the `:root` block of [src/dashboard.ts](src/dashboard.ts). Change a palette by editing those values, not by hardcoding colors at use sites.
- Webview HTML is CSP-locked with a per-render nonce. Escape all interpolated text.

## Brand

The TechTorch brand is monochrome `#252b38`. Source files are in [brand/](brand/), with the derivation of the
shipped icons documented in [brand/README.md](brand/README.md). Dashboard brand surfaces use `--brand*` and
`--on-brand*` tokens; interactive accents inherit from the editor theme (`--vscode-textLink-foreground`,
`--vscode-button-*`) so contrast holds in every VS Code theme. Do not hardcode a hex value at a use site.
